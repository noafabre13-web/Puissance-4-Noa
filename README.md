# Puissance 4 Noa

Un Puissance 4 simple et ludique, dans une seule page HTML, sans aucune dépendance.

## Fonctionnalités

- Mode **2 joueurs** sur le même écran, ou **contre l'ordinateur**
- Chute des jetons animée, derrière la façade du plateau comme dans le vrai jeu
- Aperçu du jeton au-dessus de la colonne visée
- Mise en évidence de l'alignement gagnant et compteur de score
- Jouable au clavier : touches 1 à 7, ou flèches puis Entrée

## Jouer

Téléchargez `index.html` et ouvrez-le dans votre navigateur. C'est tout.

## Comment joue l'ordinateur

1. S'il peut gagner tout de suite, il joue ce coup.
2. Sinon, il bloque votre coup gagnant.
3. Il évite de poser un jeton qui vous offre la victoire juste au-dessus.
4. Sinon, il privilégie le centre, avec un peu de hasard.
